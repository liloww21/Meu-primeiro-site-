🌐 Meu Primeiro Site

Projeto desenvolvido como uma experiência de criação de um site, utilizando tecnologias de desenvolvimento web.

📌 Sobre o projeto

Este projeto representa meu primeiro site desenvolvido para colocar em prática conceitos de desenvolvimento web, organização de arquivos e criação de páginas para a web.

O projeto contém os arquivos necessários para executar o site localmente através de um navegador.

🛠️ Tecnologias utilizadas

HTML5

CSS3

JavaScript

📂 Estrutura do projeto

A estrutura do projeto pode ser organizada da seguinte forma:

Meu-primeiro-site/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/
│   └── imagens do projeto
└── README.md


A estrutura pode variar de acordo com os arquivos presentes no projeto.

🚀 Como executar o projeto
Opção 1 — Abrindo diretamente no navegador

Baixe ou clone este repositório.

Caso esteja em formato .zip, extraia os arquivos.

Abra a pasta do projeto.

Localize o arquivo index.html.

Clique duas vezes no arquivo para abrir o site no navegador.

Opção 2 — Utilizando o VS Code

Para uma experiência melhor durante o desenvolvimento, é possível utilizar o Visual Studio Code com a extensão Live Server.

Abra a pasta do projeto no VS Code.

Instale a extensão Live Server.

Abra o arquivo index.html.

Clique com o botão direito no arquivo.

Selecione Open with Live Server.

O site será aberto automaticamente no navegador.

✨ Funcionalidades

Página web desenvolvida para fins de aprendizado.

Estrutura organizada em arquivos HTML, CSS e JavaScript.

Estilização da página utilizando CSS.

Possibilidade de adicionar interações utilizando JavaScript.

🎯 Objetivo

O principal objetivo deste projeto é praticar conceitos fundamentais de desenvolvimento web e adquirir experiência na criação e organização de um projeto de site.
